# Codebase analysis

Use when the location or contract of a behavior is unclear. Start with targeted search, changed files and symbols; read full files only when needed. Trace callers and affected boundaries, then report files, observed behavior, dependencies and unknowns. Keep the output small enough for the next worker to act without repeating the search.
