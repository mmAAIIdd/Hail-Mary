# Hail Mary

Hail Mary — веб-сервис для школьников 8–11 классов, который помогает собрать профиль абитуриента, подобрать подходящие университеты и получить понятный план подготовки к поступлению за рубеж.

**Сайт:** https://mmaaiidd.github.io/Hail-Mary/

## О проекте

Поступление за рубеж — это не один выбор университета. Абитуриенту одновременно нужно определиться с направлением и страной, оценить свои академические результаты, разобраться с экзаменами, требованиями, документами, дедлайнами и бюджетом.

Информация об этом находится в разных источниках, а обычные подборки университетов часто заканчиваются списком вариантов без ответа на главный вопрос: что делать дальше?

Hail Mary объединяет основные этапы этого процесса в одном сервисе. Пользователь заполняет профиль, после чего система анализирует введённые данные, предлагает подходящие варианты и помогает построить дальнейший маршрут подготовки.

## Что решает Hail Mary

Основная задача проекта — не просто показать пользователю список университетов, а помочь ему понять собственную ситуацию и следующие шаги.

Для этого сервис:

- собирает основные данные абитуриента через пошаговую анкету;
- учитывает академические результаты, интересы, страны, бюджет и сроки;
- проводит первичную диагностику профиля;
- подбирает университеты с помощью AI;
- объясняет рекомендации;
- помогает сравнивать варианты;
- формирует roadmap подготовки;
- сохраняет профиль и полученные результаты в браузере.

Основной пользовательский путь:

**Профиль → Анализ → Подбор → Требования → Roadmap**

## Возможности

На текущем этапе в проекте реализованы:

- адаптивный лендинг;
- интерактивная карта мира с университетами;
- пошаговая анкета абитуриента;
- сохранение профиля в браузере;
- первичная диагностика профиля;
- AI-рекомендации университетов;
- просмотр результатов подбора;

- roadmap подготовки к поступлению;
- разделы «О нас» и «Ресурсы»;
- адаптация интерфейса под мобильные устройства и компьютеры.

## Как это работает

Пользователь проходит анкету и указывает информацию, необходимую для первичного анализа профиля.

В неё входят такие параметры, как:

- интересы;
- профильный предмет;
- GPA;
- интересующие страны;
- планируемые сроки поступления;
- бюджет.

После заполнения анкеты сервис сразу показывает экспресс-разбор по ответам пользователя (без ИИ). Gemini затем подбирает три варианта университета — амбициозный, реалистичный и резервный — и составляет путь поступления из пяти этапов. Время генерации зависит от доступности Gemini; 25 секунд — цель, а не гарантия.

AI используется как часть системы анализа и подбора, а не как отдельный чат. Полученный результат отображается в интерфейсе Hail Mary и используется для дальнейшего планирования поступления.

## Технологии

| Часть проекта | Технологии |
| --- | --- |
| Frontend | React 19, TypeScript |
| Сборка | Vite |
| Стили | Tailwind CSS |
| Интерфейс | Lucide React |
| Карта | react-simple-maps, TopoJSON World Atlas |
| Хранение профиля | localStorage |
| Backend | Cloudflare Workers |
| Валидация | Zod |
| AI | Google Gemini API |

| API hosting | Cloudflare Workers |

В проекте также используется локальный шрифт `Liter-Regular.ttf`, поэтому для него не требуется отдельная загрузка шрифта через CDN.

## Архитектура

Общая схема работы проекта:

```text
Пользователь
      ↓
React Frontend
      ↓
Анкета и профиль
      ↓
Первичная диагностика
      ↓
Cloudflare Worker
      ↓
Gemini API
      ↓
Результат
      ↓
Интерфейс Hail Mary
```

Frontend отвечает за взаимодействие с пользователем: анкету, отображение профиля, диагностику, рекомендации, сравнение и roadmap.

Профиль пользователя и результат сохраняются локально в браузере через `localStorage`.

AI-запросы не отправляются из браузера напрямую в Gemini. Между frontend и Gemini находится Cloudflare Worker.

Worker принимает запрос от приложения, проверяет данные и обращается к Gemini API. Благодаря этому API-ключ не попадает в frontend-сборку.

## AI и API

Для AI-функций используется Google Gemini API через backend проекта.

Модель получает структурированные данные анкеты и возвращает результат, который затем обрабатывается приложением и отображается пользователю.

Основная Gemini-модель может задаваться через конфигурацию Worker. В backend также предусмотрена обработка ошибок при обращении к модели.

Для работы с Gemini используется пакет:

```text
@google/genai
```

API-ключ хранится на стороне Cloudflare Worker и не передаётся в браузер пользователя.

При доступности соответствующей конфигурации backend также поддерживает Google Search grounding для дополнительной проверки информации.

AI-рекомендации не считаются официальным источником данных об университете. Актуальные требования, стоимость обучения и дедлайны необходимо проверять по официальным источникам.

## Backend

Cloudflare Worker используется как промежуточный слой между frontend и Gemini API.

На стороне Worker реализованы:

- валидация входных данных;
- CORS;
- ограничение размера запросов;
- rate limiting;
- кеширование;
- обработка ошибок;
- работа с Gemini API;
- защита API-ключа.

Это позволяет не хранить секретный Gemini API key в клиентской части приложения.

## Хранение данных

Профиль пользователя хранится локально в браузере через `localStorage`.

Это позволяет сохранить заполненные данные и продолжить работу с профилем после обновления страницы.

Для AI-запроса используются данные анкеты, необходимые для формирования результата. Имя и фамилия пользователя для этого не требуются.

## Источники и данные

В проекте используются:

- данные, введённые пользователем в анкете;
- TopoJSON World Atlas для карты;
- координаты университетов для отображения маркеров;
- Google Gemini API для AI-функций;
- внешние источники, доступные пользователю через раздел «Ресурсы».

Информация о поступлении может меняться. Особенно это касается:

- дедлайнов;
- стоимости обучения;
- требований программ;
- экзаменов;
- визовых требований;
- финансовой помощи.

Поэтому Hail Mary используется как инструмент для навигации и планирования, а критически важную информацию перед подачей необходимо перепроверять на официальных сайтах университетов и государственных ресурсах.

## Локальный запуск

### Frontend

Перейдите в папку frontend:

```bash
cd frontend
```

Установите зависимости:

```bash
npm install
```

Запустите проект:

```bash
npm run dev
```

После запуска приложение будет доступно локально:

```text
http://localhost:3000
```

Для подключения опубликованного API используется `frontend/.env.local`:

```text
VITE_ADMISSIONS_API_URL=https://hail-mary-admissions-api.hail-mary-admissions-api.workers.dev
```

## Локальный запуск API

Перейдите в директорию:

```bash
cd api
```

Установите зависимости:

```bash
npm install
```

Создайте локальный файл переменных окружения на основе примера:

```bash
copy .dev.vars.example .dev.vars
```

Добавьте в него Gemini API key:

```text
GEMINI_API_KEY=YOUR_API_KEY
```

После этого запустите Worker:

```bash
npm run dev
```

Для подключения frontend к локальному Worker измените `frontend/.env.local`:

```text
VITE_ADMISSIONS_API_URL=http://127.0.0.1:8787
```

## Проверка проекта

Для проверки frontend:

```bash
cd frontend

```

Для проверки API:

```bash
cd api
npm run check
```

## Ограничения

Hail Mary не является официальным сервисом университетов или приёмных комиссий.

Результат зависит от информации, которую пользователь указал в анкете, а AI может допускать ошибки.

Рекомендация университета не означает гарантию поступления.

Стоимость обучения, дедлайны, требования программ, визовые правила и другие изменяемые данные должны дополнительно проверяться по официальным источникам.

Сервис предназначен в первую очередь для первичной навигации, подбора вариантов и построения дальнейшего плана подготовки.
